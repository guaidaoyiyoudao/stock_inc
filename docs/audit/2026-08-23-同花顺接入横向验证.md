## 三、附带发现

1. **腾讯历史缺陷被扶摇切换自愈（L1）**：腾讯 fqkline 对科创板（实测 688981）请求 qfq 时**只返回未复权的 `day` 键**（`qfqday` 为 null）——旧版 App 科创板 BOLL/K线实际拿不到前复权数据；且腾讯 qt 的 idx36 成交量字段口径跨板块漂移（主板=手、科创板=股）。扶摇主源对科创板前复权正常覆盖，该缺陷不再影响。
2. **扶摇限流实测**：审计高频调用触发过 HTTP 429（配额确实存在，文档未公布数值）。App 侧平面 60s 会话缓存 + 失败降级链（东财/腾讯）+ ErrorLog 可感知已构成兜底。
3. 东财 push2 行情接口对部分出口 IP 拒连（本机实测），新浪行情可作为行情类审计的替代第二验证源。
