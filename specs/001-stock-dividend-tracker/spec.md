# Feature Specification: Stock Dividend Tracker

**Feature Branch**: `001-stock-dividend-tracker`
**Created**: 2026-04-12
**Status**: Draft
**Input**: User description: "帮我构建一个安卓apk,可以通过用户手动录入股票名,然后根据东方财富查询对应股票的股息率;首页用户展示用户所有的股息收入总和,主页下面有一个列表展示每个股票的每年的股息收入"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - Add Stock and View Dividend Data (Priority: P1)

用户想要跟踪自己持有的股票的股息收入。用户打开应用后,通过输入股票名称(如"平安银行")添加一只股票到自己的关注列表中。系统自动从东方财富数据源查询该股票的历史股息数据,并在主页面展示该股票的逐年股息收入明细。

**Why this priority**: 这是应用的核心功能——没有股票录入和股息查询,其他所有功能都无从谈起。这是最小可行产品(MVP)的基础。

**Independent Test**: 可以通过添加一只股票并验证是否正确显示该股票的逐年股息数据来独立测试,即使没有汇总功能,用户也能获得单只股票的股息信息。

**Acceptance Scenarios**:

1. **Given** 用户在主页面, **When** 用户点击"添加股票"按钮并输入股票名称(如"平安银行"), **Then** 系统显示匹配的股票供用户确认选择,添加成功后该股票出现在列表中,并展示逐年股息数据
2. **Given** 用户在主页面, **When** 用户输入一个不存在的股票名称, **Then** 系统显示"未找到匹配的股票"提示
3. **Given** 用户已添加一只股票, **When** 用户查看该股票详情, **Then** 系统展示该股票每一年的股息金额、除权除息日等详细信息

---

### User Story 2 - View Total Dividend Income Summary (Priority: P2)

用户想要一目了然地看到自己所有股票的总股息收入。在主页顶部,系统计算并展示所有已关注股票的股息收入汇总金额,让用户快速了解整体投资回报。

**Why this priority**: 汇总视图是在单股票数据之上的增值功能,提供了整体视角,但对单股票数据的依赖使其排在P1之后。

**Independent Test**: 可以通过添加多只股票并验证首页顶部是否正确显示所有股票的股息总和来独立测试。

**Acceptance Scenarios**:

1. **Given** 用户已添加3只股票, **When** 用户打开主页, **Then** 页面顶部显示所有股票的股息收入总和
2. **Given** 用户尚未添加任何股票, **When** 用户打开主页, **Then** 页面顶部显示收入总和为0,并提示用户添加股票
3. **Given** 用户已添加多只股票, **When** 某只股票新增了股息数据, **Then** 总和自动更新反映最新数据

---

### User Story 3 - Manage Stock Watchlist (Priority: P3)

用户希望能够管理自己关注的股票列表,包括删除不再关注的股票。用户可以在股票列表中长按或滑动来删除某只股票,删除后汇总数据自动更新。

**Why this priority**: 管理功能增强了用户体验,但不影响核心的查询和展示功能。

**Independent Test**: 可以通过添加然后删除一只股票,验证列表和汇总数据是否正确更新来独立测试。

**Acceptance Scenarios**:

1. **Given** 用户有3只已关注的股票, **When** 用户删除其中一只, **Then** 列表中不再显示该股票,汇总收入自动减少该股票的金额
2. **Given** 用户只有1只已关注的股票, **When** 用户删除该股票, **Then** 列表为空,显示引导用户添加股票的空状态页面

---

### Edge Cases

- **EC-001**: 用户输入的股票名称有多个匹配结果时,系统 MUST 展示匹配候选列表(股票名称+代码)供用户选择,而非自动添加第一个结果
- **EC-002**: 东方财富数据源不可用或网络异常时,系统 MUST 展示友好的中文错误提示、已缓存的股息数据,并提供重试按钮
- **EC-003**: 股票代码与股票名称的映射 MUST 通过东方财富搜索API自动处理,用户仅需输入名称即可定位股票
- **EC-004**: 用户在弱网或离线环境下打开应用时,系统 MUST 展示上次缓存的股息数据,并在界面标注数据可能非最新
- **EC-005**: 某只股票在东方财富中没有股息数据时,系统 MUST 在该股票详情页展示"暂无股息数据"提示,而非空白页面

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 系统 MUST 允许用户通过输入股票名称搜索并添加股票到关注列表
- **FR-002**: 系统 MUST 在用户选择股票后,自动从东方财富数据源查询该股票的历史股息数据
- **FR-003**: 系统 MUST 在主页面顶部展示所有关注股票的股息收入总和
- **FR-004**: 系统 MUST 在主页面下方以列表形式展示每只股票的逐年股息收入
- **FR-005**: 列表中每只股票 MUST 展示股票名称、股票代码和按年度分组的股息金额
- **FR-006**: 系统 MUST 支持用户从关注列表中删除股票
- **FR-007**: 系统 MUST 在股票数据变更后自动更新汇总收入金额
- **FR-008**: 系统 MUST 在网络不可用时展示适当的错误提示信息
- **FR-009**: 系统 MUST 将用户的关注列表和股息数据持久化存储在本地
- **FR-010**: 系统 MUST 在用户添加股票时提供股票名称搜索匹配功能,帮助用户准确定位目标股票
- **FR-011**: 系统 MUST 支持刷新已关注股票的股息数据以获取最新信息
- **FR-012**: 系统 MUST 在股票详情和股票卡片中明确标注数据来源（"数据来源: 东方财富"）及数据最后更新时间

### Key Entities

- **股票(Stock)**: 代表一只被关注的股票,包含股票名称(如"平安银行")、股票代码(如"sz.000001")、所属市场(沪深等)
- **股息记录(Dividend Record)**: 代表某只股票某一年的股息信息,包含年份、每股派息金额、除权除息日、派息总额等
- **用户关注列表(Watchlist)**: 用户关注的股票集合,是股票与用户的关联关系
- **股息汇总(Dividend Summary)**: 所有关注股票的股息收入汇总,包含年度汇总和总体汇总

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 用户能在30秒内完成一只股票的添加并看到股息数据
- **SC-002**: 主页在3秒内完成所有关注股票的股息数据加载和汇总计算
- **SC-003**: 90%的用户在首次使用时能无需帮助即可完成股票添加操作
- **SC-004**: 应用能稳定支持用户关注至少50只股票并流畅展示数据
- **SC-005**: 股息数据与东方财富数据源保持一致,数据准确率达100%

## Assumptions

- 用户使用的是 Android 7.0 及以上系统的设备
- 用户在使用应用时具有稳定的网络连接(查询股息数据时需要)
- 东方财富数据源是免费且公开可用的,无需用户注册或认证
- 用户自行输入的股票名称为中文简称或股票代码,系统能通过东方财富 API 进行模糊匹配
- 应用的数据全部存储在本地设备,不涉及云端同步或用户账户系统
- 股息数据以人民币(CNY)为单位展示
- 每股派息金额为税前金额,不涉及税后计算
- 用户在离线时可以查看已缓存的股息数据,但不能添加新股票或刷新数据
