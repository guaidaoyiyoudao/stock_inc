# Quickstart: Holdings Dividend Forecast

**Branch**: `002-holdings-dividend-forecast` | **Date**: 2026-04-12

## 前提条件

- 已完成 001-stock-dividend-tracker 功能 (已安装应用)
- Android Studio Hedgehog 或更新版本
- JDK 17+
- Android 模拟器 (API 24+) 或真机 (Android 7.0+)
- 网络连接 (首次添加股票和刷新数据时需要)

## 构建与运行

```bash
# 1. 确保在 002-holdings-dividend-forecast 分支
git checkout 002-holdings-dividend-forecast

# 2. 构建 APK (Room 迁移自动执行)
./gradlew assembleDebug

# 3. 安装到设备 (覆盖安装, 本地数据保留)
./gradlew installDebug
```

## 功能验证

### 场景 1: 添加股票时填写持仓

1. 启动应用 → 点击 FAB (+) 按钮进入搜索页
2. 搜索 "平安银行" → 选择搜索结果
3. 在 "持有股数" 输入框输入 `1000` → 确认添加
4. 返回主页 → 股票卡片显示 "持有 1000 股" 和预测股息收入
5. 主页顶部汇总卡片显示预测年度股息收入总和

### 场景 2: 修改持仓数量

1. 点击股票卡片进入详情页
2. 点击 "编辑持仓" 按钮 → 跳转到编辑页面
3. 修改持有股数为 `2000` → 点击保存
4. 返回详情页 → 持仓数和预测收入实时更新

### 场景 3: 切换股息率档位

1. 在股票详情页 → 查看预测收入区域
2. 同时展示 1年/3年/5年 三档预测收入对比
3. 切换选中档位 → 预测收入更新
4. 返回主页 → 汇总按新档位重新计算

### 场景 4: 数据不足

1. 添加一只只有 1 年股息数据的股票
2. 选择 5 年平均 → 系统标注 "基于 1 年数据"
3. 预测收入基于 1 年数据计算

### 场景 5: 验证汇总一致性

1. 添加多只股票并输入不同持仓数量
2. 主页汇总金额 = 所有股票预测收入之和
